# Service Approval — Control Generator v3

> **DRAFT OUTPUTS — NOT PRODUCTION READY.** Every artifact produced by this skill (and its
> three sub-skills) is a draft. Outputs generated by this accelerator are not production ready.
> All generated artifacts require thorough review by your security, risk, or equivalent teams
> before deployment. No regulatory, legal, or compliance advice is provided, and no liability
> is assumed for its output. Compliance and production readiness remain your responsibility.
> Ensure alignment with your organization's policies and AWS service terms.
>
> The output directory, every subdirectory, and every output file MUST be suffixed with
> `-DRAFT` (e.g., `05-generate-DRAFT/preventive-DRAFT/scp-policy-DRAFT.json`). The disclaimer
> above MUST be embedded in the header of every generated artifact. Do NOT strip the suffix
> or the embedded disclaimer.

Read `.service-approval/<slug>/04-map/mapping-results.json` (produced by Mapper) for controls and
framework mappings. Read `.service-approval/<slug>/03-validate/validated.json` (produced by Validator v3)
for API surface and capabilities. Generate artifacts organized by the Controls Matrix
(Category x Scope). Write to `.service-approval/<slug>/05-generate-DRAFT/`.

## Sub-Skill Architecture

This skill is split into 3 focused sub-skills that write to separate directories:

| Sub-Skill | Focus | Output Directory |
|-----------|-------|-----------------|
| `generate-preventive` | SCPs, resource policies, KMS key policies, permission boundaries, tag policies, OPA, CFN Guard | `<slug>/05-generate-DRAFT/preventive-DRAFT/`, `<slug>/05-generate-DRAFT/proactive-DRAFT/` |
| `generate-detective` | Config rules, Lambda handlers, EventBridge, CloudWatch, SSM runbooks, Step Functions | `<slug>/05-generate-DRAFT/detective-DRAFT/`, `<slug>/05-generate-DRAFT/responsive-DRAFT/` |
| `generate-iac` | Terraform modules, CDK TypeScript, CloudFormation YAML, CDK for Terraform | `<slug>/05-generate-DRAFT/iac-DRAFT/` |

**When invoked directly** (via `/generate`), this skill runs all 3 sub-skills sequentially.
**When invoked by the orchestrator**, the orchestrator dispatches sub-skills in parallel.

## Agent model rule

When spawning subagents (via the Agent tool) for parallel artifact generation, do NOT specify
a `model` parameter. Omitting `model` causes subagents to inherit the caller's model.

## Prerequisites

**Hard gate — halts the run if upstream phases are incomplete.**

```bash
python3 -m tools.validate.check_phase_complete --slug <slug> --phase 03-validate || exit 2
python3 -m tools.validate.check_phase_complete --slug <slug> --phase 04-map || exit 2

mkdir -p .service-approval/<slug>/05-generate-DRAFT/{proactive-DRAFT,preventive-DRAFT,detective-DRAFT,responsive-DRAFT,iac-DRAFT}
mkdir -p .service-approval/<slug>/05-generate-DRAFT/proactive-DRAFT/opa-policies-DRAFT

mkdir -p .service-approval/<slug>/05-generate-DRAFT/detective-DRAFT/config-rule-lambdas-DRAFT
```

The check_phase_complete CLI verifies every required artifact (mapping-results.json,
controls-catalog.md, framework-mapping.md, validated.json, etc.) exists and is
non-stub. Without this gate, generate would silently skip controls when its
inputs are missing, producing an empty 05-generate-DRAFT/ tree.

Create Terraform module directories:
```bash
for asset in $(python3 -c "import json; d=json.load(open('.service-approval/<slug>/03-validate/validated.json')); [print(a['name'].lower().replace(' ','-')) for a in d['assets']]"); do
  mkdir -p ".service-approval/<slug>/05-generate-DRAFT/iac-DRAFT/modules-DRAFT/${asset}-DRAFT"
done
mkdir -p .service-approval/<slug>/05-generate-DRAFT/iac-DRAFT/modules-DRAFT/_shared-DRAFT
```

## Phase 4 Inventory

After sub-skills finish, print a one-screen inventory of what was generated. This
gives the user (and Summarize) a quick view of category counts and which IaC formats
are actually present. Runs unconditionally — no HITL gate.

```bash
python3 - <<'PY'
import json
from pathlib import Path

root = Path(f".service-approval/{slug}/05-generate-DRAFT")
categories = ["preventive-DRAFT", "proactive-DRAFT", "detective-DRAFT", "responsive-DRAFT", "iac-DRAFT"]
counts = {c: sum(1 for _ in (root / c).rglob("*") if _.is_file()) if (root / c).exists() else 0
          for c in categories}

iac_formats = {}
iac_root = root / "iac-DRAFT"
if iac_root.exists():
    iac_formats["terraform"]      = (iac_root / "modules-DRAFT").exists()
    iac_formats["cloudformation"] = any(iac_root.rglob("*.cfn.yaml")) or any(iac_root.rglob("*.yaml"))
    iac_formats["cdk-typescript"] = any(iac_root.rglob("*.ts"))
    iac_formats["cdktf"]          = (iac_root / "cdktf-DRAFT").exists() or any(iac_root.rglob("cdktf.json"))

service = None
sj = Path(f".service-approval/{slug}/03-validate/validated.json")
if sj.exists():
    service = json.loads(sj.read_text()).get("service")

formats_present = ", ".join(k for k, v in iac_formats.items() if v) or "(none)"
print(f"Phase 4 complete — {service or '(unknown service)'}:")
for c in categories:
    print(f"  {c.capitalize():13} {counts[c]} files")
print(f"  IaC formats:  {formats_present}")
PY
```
